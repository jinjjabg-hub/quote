**고객이 링크로 입력하면, 사장님이 정한 단가표로 견적이 자동 계산되고, 사장님이 확인 후 1번 눌러 보내는 견적 도구.**
중개 플랫폼이 아니다. ✅ (README, 설계도 1장)

## 3. 차별점 (왜 이걸 쓰나)

| # | 차별점 | 왜 의미 있나 | 확인 |
|---|---|---|---|
| 1 | **내 가격, 내 단가표.** 앱은 계산만, 가격을 정하지 않음 | 업체가 가격 통제권을 잃지 않음 | ✅ `js/calc.js`, 단가표는 `shops/{uid}/private/pricing` |
| 2 | **내 고객.** 링크는 사장님이 뿌림. 고객 화면에 다른 업체가 안 보임 | 숨고·당근류는 경쟁 노출·광고비 구조. 이쪽은 구독료 외 고객 모집비 없음 | ✅ 설계도 11장(추정 비교는 ⚠️) |
| 3 | **사장님 확인 후 발송.** 금액은 승인 없이 고객에게 안 나감 | 잘못된 자동 견적 방지 | ✅ 고객 제출 시 금액 없음 |
| 4 | **분쟁 예방 구조.** 견적서에 포함·불포함·현장 추가금 조건 명시, 오염도 요율 등 금액이 정해진 할증 | 현장 추가금 분쟁이 1·2순위 다음 문제 | ✅ `calculateQuote` / ⚠️ 분쟁 감소 효과는 미측정 |
| 5 | **업종 지식은 템플릿(JSON).** 업종 추가 = 템플릿 추가 | 범용 폼보다 업종 질문이 들어있음 | ✅ `templates/*.json` |
| 6 | **새 문의 → 사장님 휴대폰 알림** | 1순위 지표(첫 응답 시간) | ✅ `notifyRequest` (2026-11-11 추가) / ⚠️ 속도 개선 수치 없음 |

**경쟁 대안 (추측 포함, 조사 필요):** 숨고·당근(중개) / 엑셀·계산기+카톡(수기) / 범용 견적·폼 서비스. 이 앱의 자리는 "중개도 수기도 아닌, 내 단가표를 자동 적용하는 도구".

## 4. 포지셔닝 문장

> **혼자 현장 뛰는 청소 사장님**을 위한 **견적 링크**. 고객이 사진과 질문에 답하면 **내 단가표로 견적이 계산**되고, 확인 후 한 번 눌러 보냅니다. 고객을 대신 찾아주지 않습니다. **내 고객, 내 가격 그대로.**

메시지 순서(우선순위 1→3):
1. 문의를 안 놓친다 — 새 문의가 오면 폰으로 바로 알림
2. 견적이 빨리 나간다 — 계산은 자동, 사장님은 확인·발송만
3. 현장 추가금 다툼을 줄인다 — 포함/불포함/조건을 견적서에 미리 적음
