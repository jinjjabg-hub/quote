# 3개월 마케팅 계획: 첫 유료 업체 만들기 (2026-11-14 ~ 2027-02-13)

> 근거는 이 저장소의 사실(`점검-2026-11.md`, `설계도.md`, `pricing.html`)이다.
> 실사용 데이터가 아직 없어서 **전환율·건수 목표는 전부 (추측)** 이다. 4주차에 실제 숫자로 다시 맞춘다.

## 0. 왜 이 계획인가

| 지금의 사실 | 숫자 | 마케팅에 주는 뜻 |
|---|---|---|
| 실사용 업체 | 0곳 (인터뷰 1건) | 보여줄 사례가 없다 → 광고보다 **사례 1개**가 먼저 |
| 운영 중 업종 | 6개 중 1개(입주청소) | 첫 달은 **청소 업체에만** 판다 |
| 결제 | 코드 완성, 토스 키 미적용 | 키를 넣기 전에는 수익 0원. **가장 먼저 풀 일** |
| 요금 | 견적 10건 무료 → 월 19,900원(혼자) | 광고비를 쓰면 회수가 느리다 → 돈 안 드는 채널 우선 |
| 대표의 자산 | BNI 멤버, DiCA 명함 고객 | 이미 신뢰가 있는 사람부터 |

**목적:** "사장님이 돈을 낼 만한가"를 3개월 안에 실제 결제로 확인한다.
**목표가 아닌 것:** 가입자 수, 조회수, 팔로워.

## 1. 목표 숫자

| 시점 | 끝났다는 기준 | 비고 |
|---|---|---|
| 1개월 (12/13) | 협력 업체 3곳 사용, 그중 1곳이 **실제 견적 10건** | 설계도 8장 1단계 기준과 같음 |
| 2개월 (1/13) | **첫 유료 결제 1건**, 사례 1장(전·후 숫자) 완성 | 토스 라이브 키 필요 |
| 3개월 (2/13) | **유료 업체 5곳**, 추천으로 들어온 가입 2곳 이상 | 월 구독 약 10만 원 + 세팅 대행(2장) |

깔때기 (추측): 접촉 60곳 → 시연 20곳 → 무료 시작 12곳 → 10건 소진 6곳 → 유료 5곳.

**솔직한 계산:** 유료 5곳 × 19,900원 = 월 99,500원. 3개월 안에 큰돈은 아니다.
이 기간의 수익은 "금액"이 아니라 **"돈을 내는 업체가 실제로 있다"는 증거**다. 그 증거가 4개월 차부터의 BNI 발표·추천 자료가 된다.

## 2. 3개월 안에 수익을 앞당기는 방법 3가지

| 방법 | 왜 | 어떻게 | 확인할 것 |
|---|---|---|---|
| **① 세팅 대행** (1회 유료, 제안) | 구독료만으로는 3개월 수익이 작다. 사장님이 가장 귀찮아하는 건 단가표 입력이다 | 대표가 15분 통화로 단가를 듣고 대신 입력 + 견적 링크 QR·문자 문구까지 만들어 전달. 가격은 대표 결정 (예시: 5~10만 원) | 초기 협력 3곳은 무료로 해 주고 걸린 시간을 잰다. 공개 페이지에는 실제로 팔기 시작한 뒤에 적는다 |
| **② DiCA 명함 + 견적 링크 묶음** | 이미 돈을 내는 DiCA 고객에게 버튼 하나 추가하는 것이 새 고객 찾기보다 쉽다 | DiCA 명함에 "견적 받기" 버튼(견적 링크) 추가. 서비스 업종 DiCA 고객 목록부터 연락 | 지금은 청소 업종만 가능. 다른 업종 고객은 대기 명단으로 |
| **③ 무료 10건을 빨리 쓰게 하기** | 결제는 10건을 다 쓴 뒤에 일어난다. 가입만 하고 안 쓰면 수익 0 | 가입 당일 대표가 옆에서 첫 견적 1건을 같이 보낸다. 숨고·당근·카톡 답장에 견적 링크 붙이는 문구를 준다 | 업체별 "가입 → 10건 소진" 일수 기록 |

## 3. 누구에게 파나

**1차: 부산·경남의 입주·이사 청소 업체, 사장님 포함 1~5명.**
- 현장에 있어서 전화를 못 받고, 저녁에 견적을 몰아서 보낸다.
- 문의는 숨고·당근·네이버 플레이스·소개로 들어온다.
- 중요하게 보는 것: 문의를 안 놓치는 것, 현장에서 추가금으로 싸우지 않는 것.

**2차 (2개월 차 이후, 업종 템플릿을 실제 업체로 검증한 뒤):** 에어컨 청소, 이사, 커튼, 중문.

## 4. 할 말 (메시지)

**핵심 한 줄:** "현장에 계신 동안에도 견적이 나갑니다. 가격은 사장님 단가표 그대로."

| 사장님의 걱정 | 할 말 | 근거 |
|---|---|---|
| 문의를 놓친다 | 고객이 링크에 입력하면 휴대폰으로 바로 알림이 온다 | 구현됨 (`notifyRequest`) |
| 견적 쓰는 데 시간이 든다 | 단가표로 자동 계산, 확인하고 1번 눌러 문자 발송 | 구현됨 |
| 추가금 분쟁 | 견적서에 포함·불포함·현장 추가 조건이 미리 적혀 나간다 | 구현됨 (`calculateQuote`) |
| 숨고처럼 수수료·경쟁? | 중개 플랫폼이 아니다. 내 고객, 내 가격, 월 19,900원 | 포지셔닝 |
| 써 보고 별로면? | 카드 등록 없이 견적 10건 무료 | 요금 안내 |

**쓰면 안 되는 말:** "AI가 가격을 정해 준다", "계약금 결제", 아직 없는 업종·기능.
**주의:** "고객 78%가 먼저 답한 업체를 고른다"는 출처가 해외 조사로 보이며 국내 청소업 근거가 아니다(확인 필요). 협력 업체 숫자가 나오면 그 숫자로 바꾼다.

| 3 | **DiCA 기존 고객** | 이미 거래 중 | 문자 1통 + 명함에 견적 버튼 | 낮음 |

## 7. 바로 쓰는 문구

**BNI 60초 발표**
> 입주청소 사장님은 현장에 계신 동안 문의 전화를 못 받습니다. 저녁에 견적을 보내면 고객은 이미 다른 업체와 계약했습니다.
> 비즈마이 견적은 고객이 링크에 평수와 사진을 넣으면 사장님 단가표로 견적이 계산되고, 사장님은 확인 후 한 번 눌러 보냅니다.
> 이번 주 제가 찾는 분은 **직원 5명 이하 입주청소·이사청소 사장님**입니다. 견적 10건은 무료이고, 단가표는 제가 대신 넣어 드립니다.

**직접 연락 문자**
> 안녕하세요, 부산에서 청소 업체용 견적 프로그램을 만드는 티엠링크 송승훈입니다. 고객이 링크에 평수·사진을 넣으면 사장님 단가표대로 견적이 계산되어 휴대폰으로 알림이 옵니다. 견적 10건 무료이고 단가표는 제가 대신 입력해 드립니다. 10분 통화 괜찮으실 때 답장 부탁드립니다. (수신을 원치 않으시면 알려 주세요)

**15분 시연 순서**
1. (2분) "지난주 놓친 문의가 몇 건이었나요?" — 사장님 숫자를 먼저 듣는다
2. (3분) 내 휴대폰으로 고객 입력 → 사장님 휴대폰에 알림 → 견적 발송까지 직접 보여 준다
3. (7분) 그 자리에서 가입, 단가를 듣고 대신 입력, 테스트 견적 1건
4. (3분) 견적 링크를 숨고·당근·카톡 답장 문구에 넣어 드리고, 다음 주 통화 시간을 잡는다

## 8. 매주 보는 숫자

| 숫자 | 어디서 | 목표 (추측) |
|---|---|---|
| 접촉 → 시연 → 가입 | 구글 시트 1장 (업체명·경로·날짜·상태) | 60 → 20 → 12 |
| 업체별 견적 발송 수 | 앱 (`sentAt`) | 가입 2주 안에 10건 |
| 문의 → 발송 시간 | 앱 (요청 시각, `sentAt`) | 사례 자료의 "전·후" 숫자 |
| 유료 전환 | 토스 관리자 | 10건 소진 업체의 80% |
| 가입 경로 | 시트 | 추천 비율 |

## 9. 위험과 대비

| 위험 | 대비 |
|---|---|
| 토스 심사·키 적용이 늦어짐 | 1주차에 테스트 결제부터. 5주차까지 안 되면 유료 전환 목표를 4주 늦추고, 세팅 대행(계좌 이체)으로 먼저 수익 |
| 가입만 하고 안 씀 | 가입 당일 첫 견적을 같이 보낸다. 1주 무사용이면 전화 |
| 청소 외 업종의 관심 | 대기 명단에 적고, 그 업종 사장님 1명이 검증해 줄 때 연다 (일하는 순서 규칙 2·5번) |
| 10건 뒤 결제 안 함 | 이유를 꼭 듣고 기록. 3곳이 같은 이유면 그것이 다음 개발 1순위 |
| 직접 연락 문자 | 영리 목적 광고 문자는 수신 동의·표기 규정이 있다. 대량 발송 전 약관·개인정보 담당 확인. 그 전에는 소개·명함 교환한 곳과 전화 위주로 |
