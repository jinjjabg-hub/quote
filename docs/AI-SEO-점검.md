# AI·검색 노출(SEO) 점검 (2026-11-12)

> 목적(WHY): 사장님이 "청소 견적 자동화"를 찾을 때(구글·네이버·ChatGPT 같은 AI 검색) 이 사이트가 **정확하게** 소개되고, 반대로 **고객 개인 견적 페이지는 검색에 새지 않게** 한다.
> 범위: `quote.bizmy.net` 저장소 소스 기준 점검. **라이브 사이트는 이 세션에서 접속이 막혀(프록시 403) 직접 확인하지 못했다.** 배포본이 소스와 같다고 가정한 결과다.
> 제품 정의·쓸 수 있는 말은 [`제품-마케팅-정리.md`](제품-마케팅-정리.md) 기준.

## 1. 한 줄 결론

**노출 이전에 "새면 안 되는 것"이 열려 있고, "노출할 페이지"는 사실상 요금 안내 1장뿐이다.** 다만 실사용 업체 0곳 단계라, 랜딩 페이지 제작은 협력 업체 10건 이후로 미루고 아래 P0(30분 이내)만 먼저 한다.

## 2. 점검 결과

## 3. 왜 이 순서인가 (지침 규칙 적용)

규칙 1의 3줄(P0 묶음):
- ① 바꾸는 숫자: 직접 지표는 없음. **고객 견적서 외부 노출 0건**(안전), 공개 페이지 사실 오류 0건(지침 4번).
- ② 누가 쓰나: 공개 페이지 방문자(잠재 사장님·PG 심사·AI 검색 이용자), 견적서를 받는 고객.
- ③ 끝났다는 기준: 세 화면에 noindex, `robots.txt`·`sitemap.xml` 배포 후 `…/robots.txt` 응답 200, 요금 문구 ⚠️ 항목 0.

P1 이후(랜딩·JSON-LD·FAQ)는 **규칙 2**(한 번에 한 단계)에 따라 협력 업체 실제 견적 10건 뒤. 지금 단계의 1순위 지표는 SEO가 아니라 첫 응답 시간·견적 발송 시간이다. 검색 유입은 이 지표가 나온 뒤에야 "무엇을 말할지"가 정해진다.

## 4. 라이브 사이트에서 직접 확인할 것 (브라우저에서 1분)

1. `https://quote.bizmy.net/robots.txt`, `/sitemap.xml` 이 404인지
2. 구글에서 `site:quote.bizmy.net` 로 색인된 주소 확인 — `view.html?id=` 가 보이면 즉시 노출 중
3. `https://quote.bizmy.net/pricing.html` 표시 문구가 소스와 같은지

결과를 알려주시면 P0 파일(noindex·robots·sitemap)과 요금 문구 수정을 한 번에 만들어 드리겠습니다.
