무료 크레딧체험 · 추천 보상먼저 차감 · 유효기간 · 환불 불가
유료 크레딧구매나중 차감 · 미사용분 환불 규정
추천받은 업체가입 즉시 +5건추천 코드를 넣을 이유
추천한 업체상대가 견적 5건 발송 시 +10건가짜 가입 방지
크레딧은 현금 교환·양도·판매 불가, 서비스 이용료 전용입니다. 유료 크레딧 환불·유효기간은 도입 전 세무사·법률 확인이 필요합니다. 숫자는 예시이며 협력 업체 데이터로 정합니다.

개별 업체 맞춤 개발은 하지 않습니다. 업체마다 다른 것은 설정 칸으로, 업종마다 다른 것은 템플릿으로 표현합니다. 이것이 코드를 하나로 유지하는 방법입니다.
